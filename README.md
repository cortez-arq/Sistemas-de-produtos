*Sistema de Cadastro e Gerenciamento de Produtos*
Descrição

Este projeto foi desenvolvido em Python para realizar o cadastro, gerenciamento e análise de produtos utilizando um dicionário.

*O programa permite*:

Cadastrar 5 produtos com validação de nomes.
Definir o preço de cada produto.
Exibir todos os produtos cadastrados.
Calcular a soma total dos preços.
Calcular a média dos preços.
Identificar o(s) produto(s) mais caro(s).
Identificar o(s) produto(s) mais barato(s).
Remover produtos do cadastro pelo nome.
Funcionalidades
Validação de nomes

*O sistema impede*:

Nomes vazios.
Nomes iniciados com espaço.
Nomes terminados com espaço.
Produtos com nomes repetidos.
Cadastro de preços

*Os preços devem ser*:

Numéricos.
Maiores que zero.

Caso um valor inválido seja informado, o programa solicitará uma nova entrada.

Estatísticas

*Após o cadastro dos produtos, o sistema exibe*:

Soma total dos preços.
Média dos preços.
Produto(s) mais caro(s).
Produto(s) mais barato(s).
Remoção de produtos

O usuário pode informar quantos produtos deseja remover e digitar seus respectivos nomes.

Caso o produto não exista, o sistema exibirá uma mensagem de erro e solicitará outro nome.
